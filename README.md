# KisanMitra 🌱

**An AI-powered agricultural platform for farmers.**

## About the Project

KisanMitra aims to help farmers make informed farming decisions by providing personalized crop recommendations, government scheme information, crop disease detection, and yield and market price predictions.

The platform uses farmer profiles, agricultural data, machine learning, and external data sources to provide recommendations relevant to each farmer's conditions.

## Key Modules

1. **Farmer Profile and Data Management** — Stores farmer and farm information for personalized recommendations.
2. **Government Schemes and Subsidy Management** — Helps farmers discover relevant government schemes and understand application requirements.
3. **Personalized AI/ML Recommendation System** — Recommends suitable crops, farming practices, and government schemes based on farmer-specific information.
4. **Crop Disease and Pest Detection** — Analyzes uploaded crop or leaf images to identify possible diseases and pest infestations.
5. **ML-Based Yield and Price Prediction** — Estimates crop yield and predicts market price trends to support farming and selling decisions.
6. **Location-Based Market Insights** — Helps farmers explore market information and assess selling opportunities in different locations.

## Technology Stack

- **Frontend:** React
- **Backend:** FastAPI
- **Database:** PostgreSQL
- **Machine Learning:** Python, Pandas, NumPy, Scikit-learn
- **Version Control:** Git and GitHub
